S(16) proof replay

Run from the workspace root with Magma V2.30-1 and Sage Python. Save each
Magma command to its corresponding .log file. Scripts use the installed
mdmagma library at their AttachSpec paths. The authoritative result is
final_coverage.json, and PROOF.txt states all mathematical implications.

Global bound and examples:
 python work/degree16/prepare_bound.py
 python work/degree16/find_occurrences.py
 magma -b work/degree16/verify_occurrences.m

Finite-field inputs and local ordinary computations:
 magma -b work/degree16/census_sources.m
 magma -b work/degree16/census193.m
 python work/degree16/run_ordinary.py
 python work/degree16/run_pairs.py
 python work/degree16/mixed_sieve.py 41
 python work/degree16/mixed_sieve.py 43
 python work/degree16/mixed_sieve.py 73

The 12 degree2 cusp-pattern checks at193 are simple pair-rank checks and
are repeated in verify_auxiliary.py. The prior exact native certificates,
finite-image polynomial data, actual-Jacobian data at53,61,73, and the
137+254 earlier pair matrices are intentional dependencies, checked by
the two scripts below. The finite-image data at43 and193 are new.

Independent checking and final result:
 python work/degree16/verify_ranks.py
 python work/degree16/verify_auxiliary.py
 python work/degree16/verify_coverage.py
 python work/degree16/finalize_result.py

The external gonality theorem and the model of the genus9 quotient at43
are from Marin Varivoda, hexagon:2610.00219v1. The accompanying repository
is pinned at 66c5f61e9ead7ea430f6d2c8538237e01a83e652. The needed torsion
relations are rechecked here with a focused script: one principal
38-times cusp difference, together with the cyclic permutation of the
three cusps, gives both needed relations. The discarded full replay
in torsion43_classes_Q.log is not a proof input.

Exploratory q5/q11 tests, actual-Jacobian two97 computations, native43
and native53 batches and search43 are not used. In particular, their
rank defects, resource limits or stopped batches are not exclusions.
